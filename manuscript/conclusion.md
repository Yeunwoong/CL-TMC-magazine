# VI. Conclusion (Skeleton)

This manuscript skeleton positions CL-TMC as a framework-level shift from static data-centric sensing toward closed-loop, task-aware sensing control in multi-modal IoT systems.

The central message is that sensing should be driven by what is necessary for task success under current constraints, not by fixed all-data collection policies. In this framing, multi-channel sensing is consistently handled as a domain-specific extension of multi-modal sensing.

Representative use cases in localization and biomedical prediction illustrate how the same CL-TMC logic can be adapted across domains to balance task quality with sensing, communication, and processing overhead.

Future work should prioritize rigorous benchmarking, stable feedback design, deployable control methods, and privacy-/interoperability-aware implementation pathways.
