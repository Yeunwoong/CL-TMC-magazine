# A Closed-Loop Framework for Task-Aware Multi-Modal Sensing Control

## Abstract (Skeleton Placeholder)

- This article argues that future IoT sensing systems should move from static data-centric collection to task-aware closed-loop sensing control.
- We introduce the closed-loop framework for task-aware multi-modal sensing control (CL-TMC), where task-level feedback guides sensing actions across modalities, sampling rates, and transmission strategies.
- We discuss representative use cases (energy-efficient localization and multi-channel biomedical prediction as a domain-specific extension) and highlight open issues for practical deployment.
